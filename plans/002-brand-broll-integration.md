# 002 — Cohesive AI Brand B-Roll Integration

**Written against commit:** `ed3cc16`
**Category:** Direction / Design · **Effort:** M · **Risk:** S · **Confidence:** High
**Depends on:** brand clips must exist in `cleanlines-studio/public/videos/` (see step 0).

## Why this matters
The section backgrounds and example tiles currently use **random uploaded clips**
(`public/videos/example-1..4.mp4`, `ambient-1..3.mp4`, `reel-1..3.mp4`, `showreel.mp4`).
They are not on-brand and not cohesive — the single biggest "looks templated vs. crafted"
tell for an award jury. Replace them with a cohesive set of **champagne-gold cinematic brand
b-roll** generated by Higgsfield (Nano Banana Pro still → Kling 3.0 motion, the cheapest model
that fits at ~7.5 credits / 5s clip).

## Step 0 — Asset production (done by the operator with Higgsfield, NOT by the executor)
Produce ~6 cohesive 16:9 brand clips, dark-black + champagne-gold, no text:
1. `brand-gold-flow.mp4` — liquid gold light ribbons on black (hero / content-compare).
2. `brand-particles.mp4` — drifting golden dust + bokeh (services / pricing bg).
3. `brand-studio.mp4` — cinematic content-studio at night, gold rim light (final-cta).
4. `brand-phone.mp4` — macro premium phone showing a reel, gold grade (reel cinema / OS phones).
5–6. two more atmospheric variants for variety.
Pipeline: `nano_banana_pro` (2k, 16:9) still → `kling3_0` image-to-video (`start_image`, 5s,
`mode:std`, `sound:off`, 16:9). Download each, place in `cleanlines-studio/public/videos/` with
the names above. **Executor assumes these files already exist** — if any is missing, STOP and report.
